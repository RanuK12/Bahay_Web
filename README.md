# Bahay Design — Architettura e Interior Design

Sito web statico per Bahay Design, studio di architettura e interior design di Cristina Cocco.

## Contenuto
- Home, About, Servizi, Progetti, News, Eventi, Contatti
- Showcase di progetti di interior design e restyling
- Servizi: progettazione, restyling, consulenza online, restyling colori

## Stack
- HTML5 + CSS3 puro
- JavaScript vanilla
- Font: Lora, Marmelad, Quicksand
- Hosting: GitHub Pages (dominio personalizzato via CNAME)

## Deploy
Sito statico: aprire `index.html` in qualsiasi server o deploy su GitHub Pages.
